# ROLIPA 3D

Sitio estático preparado para GitHub Pages.

## Publicación

1. Subir todos los archivos de esta carpeta a la raíz del repositorio.
2. En GitHub, abrir **Settings → Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Seleccionar la rama **main**, carpeta **/(root)** y guardar.

El sitio quedará disponible en:

https://leonelgallop1-boop.github.io/rolipa-3d/
